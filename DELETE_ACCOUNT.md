## How to Request Account Deletion

Send an email to: mission@neuroorbitai.com

**Subject:** Account Deletion Request  
**Include in email:**  
- Your registered email address  
- The text: "I request permanent deletion 
  of my account and all associated data"

We will process your request within **30 days.**

## What Gets Deleted

| Data | Action |
|---|---|
| Email address | Permanently deleted |
| Password (hashed) | Permanently deleted |
| User ID | Permanently deleted |
| Session metadata | Permanently deleted |
| Audio data | Never stored — nothing to delete |
| Translation text | Never stored — nothing to delete |
