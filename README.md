# AI Quiet Translator

Real-time AI voice translator built for high-noise industrial, field, and professional environments.
Powered by Flutter, AWS Serverless, and WebSockets.

---

## What It Does

Quiet Translator listens to speech through your device microphone and delivers a real-time translated
transcript on screen — optimized to cut through background noise from machinery, crowds, and wind.
Nothing is saved. Everything is live.

**Key features:**
- Real-time speech-to-text and translation via AI
- Three noise environment modes: Quiet / Normal / Noisy
- Bluetooth headset support — translation plays directly into your ear
- Mode chips (MEET / CHAT / FOCUS) — each stores your preferred audio settings
- Zero data retention — audio and transcripts exist only on screen, in real time

**Powered by:**
- OpenAI Whisper — speech transcription
- Deepgram — real-time transcription
- AssemblyAI — real-time transcription
- DeepL (via AWS Serverless Proxy) — text translation
